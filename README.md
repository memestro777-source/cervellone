🧠 Big Brain!
A fast-paced brain-training game. Test yourself across four categories — Visual, Logic, Math and Memory — earn a brain size in cm³, and beat your record.
Single HTML file, zero dependencies, works offline.
________________________________________
Game Modes
•	🎲 Random challenge — 4 stages of 45 seconds, one surprise minigame per category
•	🎯 Custom challenge — same 4 stages, but you pick every game
•	🎮 Single game — practice any of the 16 minigames on its own, with a personal best saved per game
________________________________________
The 16 Minigames
👁️ Visual — Cube Counter · Missing Piece · Bubbles · Odd One Out
🧩 Logic — The Gears · Hexagon Path · The Balance · Symbol Sudoku
➗ Math — Missing Operators · Number Plate · Clock Difference · Broken Equality
💭 Memory — Flip & Find · Shape Order · Music Sequence · Memory Grid
